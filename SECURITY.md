# Segurança

## Versões com suporte

Só a [versão mais recente](https://github.com/lux-insider/iso2god-pt/releases/latest)
recebe correções.

## Como relatar uma falha de segurança

**Não abra uma issue pública.** Use a aba
[**Security → Report a vulnerability**](https://github.com/lux-insider/iso2god-pt/security/advisories/new)
do repositório: o relato fica privado até a correção sair.

Conte o que acontece, como repetir e, se possível, um arquivo de exemplo
(sem dados pessoais). A resposta vem em até 7 dias.

## O que o programa faz com os seus arquivos

- Não acessa a internet.
- Nunca altera a ISO original: grava sempre em outro arquivo ou pasta.
- Não substitui arquivos existentes sem a sua confirmação.
